# GEEK'S GADGETS AND GIZMOS CHANGELOG

## 2.0.0
  - New theme
  - Introduced the Triple G Pager module to translate Drupal's zero-based pager into one-based URLs.
  - Added the Triple G Search module to map the public "q" query parameter onto the search View's "keys" filter.
  - Created a custom error page component with responsive design and improved accessibility features.
  - Updated SCSS styles for error pages, search forms, and site shell components to enhance visual consistency.
  - Implemented new Twig templates for 403 and 404 error pages, including search functionality.
  - Refactored existing layout templates to streamline header and footer structures.
  - Adjusted pager template to handle current page states and improve link accessibility.
  - Removed breadcrumb region from the site shell for a cleaner layout.
  - Reorganized and refactored AI agent skills and personalities, including the ability to hand work off to a different agent for out-of-scope items
